# 🌐 InspireWorks Templates — Launch Your Dream Website

This repository contains the full source code for the **InspireWorks Templates** landing page — the all-in-one entry point for exploring our website templates, browsing real portfolios, and understanding our pricing plans.  
Visit the live demo: [https://inspireworks-templates.netlify.app/](https://inspireworks-templates.netlify.app/)

---

## 🏁 Project Purpose & Overview

The landing page serves as the hub for our clients to:

- Discover a collection of *stunning, responsive and customizable website templates* built for every business type.  
- Understand why they should choose us — our expertise, reliability, on-time delivery and client satisfaction.  
- Browse **our portfolios**, especially in restaurant and business/agency sectors, to see real-world examples.  
- Choose from clearly defined pricing plans with both INR and USD views for transparency.  
- Get in touch quickly — all in one streamlined interface.

## 🧰 Setup & Deployment

This is a **static site** built using:

- HTML5  
- CSS3  
- JavaScript  
- Bootstrap 5  
- Font Awesome icons  

### ✔ Prerequisites  

Make sure your `<head>` section includes:

```html
<!-- Bootstrap CSS -->
<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">

<!-- Font Awesome -->
<link rel="stylesheet" href="https://cdnjs.cloudflare.com/ajax/libs/font-awesome/6.5.0/css/all.min.css">
